# wv-field-plaintext

## Purpose

`<wv-field-plaintext/>`. Renders a plaintext string in the place of a field input. Has label, description and all other field properties.


## Properties
**Important**: All `<wv-field-*>` helpers inherit a ["base tag helper" properties](wv-field-base.md). In the following list are presented only the properties that this tag helper adds or alters. Not all base tag helper properties can be implemented by this tag helper too.

+-------------------------------+-----------------------------------+
| name                          | description                       |
+===============================+===================================+
| does not have any specific properties                             | 
+-------------------------------------------------------------------+

## Example

```html
<wv-field-plaintext value="@someText"></wv-field-plaintext>
```
