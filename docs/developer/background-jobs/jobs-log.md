# Background jobs log

You can review the list of all subscribed schedule plans as well as the already schedule background jobs in the SDK Application > Server > Background jobs. These schedule plans and background jobs currently run inside the web application host; a dedicated background worker host (`WebVella.Erp.Worker`) is planned but not yet implemented.
